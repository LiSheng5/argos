## 3. ✅ 覆盖缺口 —— **已补上**（2026-09-19）

原来查出的两条缺口（功能做了、benchmark 没覆盖）已补齐，benchmark 从 24 场景 → **35 场景 /
630 组**：

| 缺口 | 补法 | 结果 |
|---|---|---|
| 9 类失败只测了 1 类 | 新增 `route_failure`（`path_invalid`）+ `nonroute_failure`（六个非路线类）场景族 | **9 类全部有场景跑到**（`network_delay` 走丢包剖面）；并加了**覆盖守卫测试**钉住 |
| 感知层没进 benchmark | `Scenario.sensors` + 三个感知场景（噪声 / 失灵 / 探测半径受限）| 感知首次被量化 |

补齐过程中**抓到并修掉一个真缺陷**（详见 `文档/REFLECTION_LOOP.md` §1b）：
`route_ok` 原来用 `failures == 0` 当判据 → 非路线类失败也被算成"这条路不顺" →
语义层把路线降权 → **agent 因为定位漂移改走远路**（证据：学习臂比无记忆臂多 2.00 个动作、
失败数却一样）。现在判据与 Procedural 层同源（只用 `ROUTE_REASONS`）。

## 4. 已知的技术债（有明确触发条件就动手）

- **Planner 仍绑 `MiniWorld` 的路线拓扑**（`argos/run.py::_route_topology` 取不到时如实抛错，
  不假装 backend 无关）→ 真机 backend 要么自带拓扑，要么把拓扑改成从 `Observation` 里取；
- **反证规则只收紧了一层**（D-02，2026-09-20）：现在要**连续 2 次**探针成功才削弱教训，
  中途该路线再失败会清零重数。剩下的债：① "连续 2 次"这个数**也是拍的**（没扫过）；
  ② 仍是 `hits -= 1` 的**二值降级**。更严谨的形态是把路线选择当**非平稳多臂老虎机**
  （折扣/滑窗或变点检测），而不是二值 `avoid`；
- **教训只落盘了一半**（D-03a，2026-09-20）：`LessonStore.save/load` + `--lessons` 已能把
  **Procedural（Lesson）**写进 JSON 并在启动时载回；**Episodic 原始事件与 Semantic 滑窗
  仍只在内存**，重启后从零起算。**人工审阅/编辑入口**（文献里的 "operator curates the buffer"）
  也还没有；
- **阈值已扫过参但未做交互扫描**（单变量，见 `文档/SWEEP.md` §3）。

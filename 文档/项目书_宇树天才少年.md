## 二、项目是什么

**ArgOS** 是宇树 Go2 机器狗的大脑：一句话指挥，安全闸守护。

```
用户说话 / OpenClaw
      ↓
  server.py（127.0.0.1:8766）
      ↓
  RobotBrain：编译 → 落账口 → 记忆/反思
      ↓
  RobotBackend：过 SafetyGate（白名单/禁触/急停/电量/边界）
      ↓
  ┌─────────┬──────────┬──────────┬──────────────┐
  │  stub   │  mujoco  │   dds    │ real（高层） │
  │ 瞬移    │ 有物理   │ 会真走   │ SportClient  │
  └─────────┴──────────┴──────────┴──────────────┘
```

核心设计哲学：**LLM 只提议、代码决定执行**——所有动作必须命中运动原语白名单并过安全闸，AI 零关节/零文件直控。大脑层与执行器层分离，真机到手只需换执行器，大脑一行不改。

## 四、完成了什么（诚实版）

**大脑层**（已完工，126 项测试全绿）：

- **一句话编译**：规则词表把"去门口/巡逻/拿某物/放下"编译成任务单，听不懂就老实说听不懂
- **落账簿**：先记账后干活；失败冷却；急停期间拒绝接单
- **安全闸**：动作白名单、禁触字段递归扫描、急停双通道（闸门+执行器联动，正在跑的那一段也能中断）、电量门控（未知电量 = 拒绝巡逻，fail-closed）、工作空间边界
- **断链看门狗**：链路一断狗自动收速停下，不自动恢复、必须人工复位——15kg 的机器狗带着惯性冲出去不是开玩笑
- **记忆系统**（完整移植自我的游戏 NPC 框架）：
  - 语义检索：recency + 相关度（原词/同义词族 + 真 BM25）+ 重要度 + 一跳关联；可选温层向量锚点（chromadb）RRF 融合
  - 反思归纳：重要事攒够 → 归纳 1-2 条结论，或提炼三分类记忆（persona/episodic/instruction）；噪音批静默翻篇
  - 遗忘合并：同主题流水账并成一条；弱旧记忆按 72 小时半衰期淡出
  - 红线：反思/合并/归档条目永不物理删除；记忆卡 = 可编辑 JSON
- **性格系统**：persona.json 直接编辑狗的说话风格（可选 LLM，无 key 自动纯规则）

**真机代码**（已写好，待真机验证）：

- RealSportEntity：走官方高层 SportClient（狗的小脑负责行走与转向），自己写"先转后走"闭环控制器 + 卡住检测 + 超时放弃
- 假狗实测收敛：正前方 2m ≈ 5s、掉头 ≈ 9s、斜前方 (2,2) ≈ 10s，终点误差 ≤ 0.25m

**物理仿真全链路**（宇树官方仿真世界实测）：

- 一句话"去桌边" → 编译 → 落账 → DDS 电机级指令 → MuJoCo 物理世界里**真实行走 2 米** → 到点记账
- 航向漂移实测 4 次：1.4° / 19.9° / **163.2°** / **85.3°**——由此得出结论：低层 trot 步态是开环的会打转，不可用于导航；真机走高层 SportClient 才是正解。**失败数据也是结论的证据。**

**还没做的**（诚实交代）：

- 尚未在真机上运行——真机联调清单已备好（`文档/真机安全清单.md`）
- 转弯/航向闭环、避障接入、真实电量（BMS）——全部卡在硬件上，软件侧能做的已做完
- 硬件门槛已查证：Go2 只有 X（基础支持）/ EDU（支持）开放二次开发
